# Edutu Growth and Analytics

Use the existing repo skills for specialist execution: `analytics`, `seo-audit`, `content-strategy`, `copywriting`, `onboarding`, `churn-prevention`, `ab-testing`, and `attribution`. This skill provides Edutu workflow context and does not replace them.

## Workflow

- Tie each initiative to a learner segment and an outcome such as successful onboarding, relevant opportunity discovery, saved/application-tracked listings, roadmap progress, repeat use, or paid conversion.
- Inspect current page routes, SEO output, event definitions, and analytics availability before proposing changes. Do not assume tracking exists because a package is installed.
- Define baseline, audience, time window, primary metric, guardrail metrics, and decision rule before calling an effort an experiment. Distinguish correlation from causation.
- Keep scholarship and education claims accurate; align messages with actual product behavior and current eligibility/content policies.
- Report the change, target learner action, measurement method, and known data gaps.
