# Edutu Creator and Partner Operations

Use current platform rules and admin workflows. Do not promise publication, payment, API access, or learner outcomes without evidence from current configuration and policy.

## Workflow

- For creators, track application, identity/status, listing or roadmap quality, moderation state, enrollment, payout/entitlement implications, and required corrections.
- For partners, establish the use case, API key/scope, data minimization, rate/usage expectations, error handling, and escalation route before technical onboarding.
- Keep privileged status changes and payouts in reviewed server-side workflows. Preserve an audit trail for decisions and corrections.
- Route product defects to the corresponding backend/web/mobile skill and flag cross-platform/API contract changes.
