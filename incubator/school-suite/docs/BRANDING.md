# White-label brand configuration

The portal/tenants.js file holds **public demo fixtures**, not production accounts. It demonstrates independent institution names, monograms, palettes, academic years and role-specific navigation.

Brand schema proposal (server-managed, one per verified institution):

- tenant_id: opaque stable ID, generated by provisioning service
- verified_domains: domains approved by DNS challenge / operator validation
- display_name, monogram, verified_logo_url, palette.primary, palette.soft
- country, currency, timezone, academic_calendar, term_labels, grading_policy
- enabled_modules: attendance, admissions, fees, library, exams, communications, AI
- institution-admin memberships and paid subscription status (stored separately)

The default demonstration brand is Evolve Academy under an Evolve-branded shell. It is a placeholder, not a final trademark clearance.

**Production requirements:** resolve tenant from trusted request host + authenticated session; store tenant config server-side; escape content; allow only approved logo/storage paths; apply CSS token validation; maintain audit of branding edits. No tenant should be able to edit another tenant's theme, data, balances or school settings.

Upstream MIT licenses/copyright notices remain intact even when the visual identity changes. White-labeling is not permission to remove license and copyright notices from source distributions.
